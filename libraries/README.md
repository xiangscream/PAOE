## 操作与参考
<!-- paoe:reading-header:end -->

本目录是 PAOS canonical Workflow / Skill 共享 Library 的**机器本地安装根**（正文不写死版本；实际运行/版本读 `paos health` 与安装实体，采用事实以唯一发布记录为准）。

- `workflow/`：Workflow Library（Guides / Workflows / Templates）
- `skill/`：Skill Library

正文事实源始终是各 Library 内的 Markdown 与 `.paos/` 索引；根 registry 记录于安装实体（不在此目录）。定位见 [workflow 导航](workflow/README.md#定位)。
