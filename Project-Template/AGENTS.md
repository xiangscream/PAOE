## PAOE · Agent 运行指南

PAOE 是 Human 和多名 Agent 共同工作的本地环境。Human 给出目标、做关键取舍；Agent 结合已有经验和方法独立推进，需要配合时直接找同事。阶段结束时，接手人应能从原件看懂来由、现状与下一步。

| 核心职责 | 去哪里 |
| --- | --- |
| 恢复工位、联系同事、查运行规则 | **System** 提供工位入口、联系工具、通用指南和模板。 |
| 查当前业务口径、依据、团队分工 | **Projects** 各库保存最新口径（INDEX）、成员分工（TEAM）、阶段成果（HISTORY）。 |
| 查已有做法、沉淀通用能力 | **Libraries** 保存工作流（Workflow）、专业技能（Skill）与本机工具（Tool Catalog）。 |
| 检索跨项目经历、原话与取舍 | **EXM** 保存团队背景与跨项目记忆。先检索定位，再回到原件上下文。 |

### 1. 从当前任务恢复

新会话、接班或压缩后，从本人 ENTRY 取得 CLI 前缀。已登记接收器的 Codex 本人在原 Desktop 执行 `orient <project> <本人Sxxx> --resume`（同时准备接收器并读取 AGENTS、INDEX、ENTRY、TODO）；其他 Harness 执行 `orient <project> <本人Sxxx> --read`。完整阅读返回内容，再读当前任务原输入。准备失败时保留具体错误交 Rooter，继续能做的事。Rooter 从安装级 ENTRY 执行 `attention rooter-show --resume`。

恢复 Current 和当前输入后，在写新 TODO 或第一份实质计划前读页首的短「共同背景」。进入新阶段或压缩后继续规划时也重读，并联想可复用的结论和同事。**遇事不决，先查 EXM。** 拿不准做法、取舍或以前为何这么定时，从页首经历入口找相似情境，读当时的条件、原话和后续纠偏，再决定这次怎么做。把仍适用的判断写进当前方案：链接那次经历的原件，说明它改变了哪一步。若只找到通用方法，把做法作为本次建议，继续核实有关往事的说法。

项目用编号（如 3002），成员用全局员工号（如 S070），工位在 `Workstations/Sxxx`。从本人 TODO 和当前输入确定下一动作；Human 改变优先级或新输入解除阻碍时，更新 Current 并接续。

### 2. 把责任落到 TODO

所有行动以本人工位唯一生效的 `TODO.md`（v4）为准。新任务接入对应 Task；确有新责任时新增。Current 只写当前焦点：

- **目标（Objective）**：本次要交付的结果。
- **下一步（Next action）**：一项能直接开始的具体动作。
- **等待（Waiting）**：缺谁的什么输入、收到后如何接续；无则留空。
- **在途（Inflight）**：已发出而尚未完成的操作；未来计划不算在途。

本人维护 TODO。只改 Current 用 `attention todo-update`；改 Tasks/Pinned 用带原文指纹的 `todo-write`，冲突先重读。读信、处理 Notice、完成任务均分别记录。

### 3. 用已有方法和工具推进

已授权的简单修改，由执行者自查后直接交付。

- **查方法与工具**：准备自行设计流程、重新配置工具，或首次处理某类产物时，先从 Libraries 找已有做法。知道方法就直达原页，否则用 `paos library search "动作或产物"`。读命中的操作段，直接把适用步骤用到本次交付；本机工具沿 `library tools` 登记的入口调用。
- **求助与协同**：找不到接口或运行报错，保留断点联系维护者；成员分工查 `TEAM` 或 `paos peers`。技术问题直接找负责同事，安装与原生接收找 Rooter，方向分歧与跨组协同找 Coordinator。Coordinator 抓目标、优先级与阻碍，普通修改不逐项等批。

### 4. 阶段完成或交接时整理成果

修改任何文档，严格遵守“**云端或项目原件为唯一事实源、写前保护人工编辑、写后必须回读验证**”。

- **成果归位**：录音、下载与原始附件归入 Materials 对应主题；项目成果归入 Works/Decisions。外部或云端文档保留稳定链接。
- **交付与收口**：写后回读受影响内容，交付时给出原件链接与具体修改点。阶段完成或交接时，合成人将共识与新成果更新至 INDEX，阶段总结记入 HISTORY。每个成员结束一阶段时，看看项目 INDEX 自上次阅读以来是否有变化。有变化就读改动的部分，判断是否影响自己的任务，据此更新 Current 和下一步。
- **重要会话提取**：阶段完成或交接时，Human 直接参与的任务按 `session-extraction` 保留本阶段原话与产物。Agent 独立完成的任务直接引用成果记录。把原件和下一动作交接手人，同时把来源与成果入口交 EXM 整理者。
- **工位收敛**：归档已完成 Task，移出已失效的草稿，保持工位干净。结束且无在途依赖的过程件移入库外历史。

### 5. 交接并持续改进

需下游行动时，用 `agent send --remind` 一次交清材料、原件链接与下一动作。被唤醒后先读原信，及时沿原渠道回给唤醒者一句话：接下了什么，下一步做什么；遇阻就回具体缺口。能当场办完的直接回结果。发起人收到反馈后按约定节点继续。投递状态不明时查原消息一次。多人讨论用 CAT，行动回 TODO，结论回项目。

指令改变优先级时，立即校准 Current 并优先执行，完成后接回原线。交付后继续授权内下一步，仅在确有外部依赖时等待。压缩前固化 Current、成果与在途状态，沿 Harness 正常入口完成压缩，再按第 1 步恢复。

发现重复劳动或失效文档，先解决当前事，顺手修小项；通用改进交方法维护者统一更新，不在工位私自复制多套。
